# 00 项目总览与状态规范

## 项目目标

完成 Things iPhone Light Mode 高保真复刻，并形成 HarmonyOS 可实施、可验证的方法体系。

目标不是截图复制，而是恢复：

* 产品语义
* 信息架构
* 交互模型
* 数据模型
* 视觉节奏

## 状态定义

### SPEC\_READY

规格完成，可以进入开发。

### IMPLEMENTED

代码存在并可运行。

### VERIFIED

有真实运行证据，包括截图、测试或审计结果。

### PENDING\_EVIDENCE

功能或规格存在，但缺少验证材料。

禁止将规格误认为实现完成。
