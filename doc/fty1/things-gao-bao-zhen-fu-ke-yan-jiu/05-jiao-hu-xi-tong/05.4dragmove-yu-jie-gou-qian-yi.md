# 05.4｜Drag、Move 与结构迁移

拖拽同时包含视觉 Interaction State 与真正的数据命令。

Todo drag 需要解决源上下文、目标上下文、插入位置、Heading 合法性与 ContextOrder；Project/Area/Heading drag 还涉及结构级移动。

Heading 已确认支持创建、选择与 Move。其 Move 到另一个 Project 时，语义上必须连带 Heading 下的 child Todos 共同迁移；但完整 group drag preview、插入指示、haptic 和 motion 仍需要 A 级补证。

组件只产出 `DragIntent`，Domain 层负责合法性和最终 mutation。
