# 05.5｜Quick Find：全局寻址与深度搜索

Quick Find 不只是搜索框，而是 Things 的全局寻址层。

第一层应快速定位：系统列表、Area、Project、Tag、Heading 等导航目标；Continue Search / 深度搜索进一步进入 Notes、Checklist、Logbook 等内容。

因此技术上建议两个索引层：

```
NavigationIndex  // 极快，标题与路由实体
ContentIndex     // Notes / Checklist / Historical items
```

Quick Find Overlay 是全局 UI 层，不应该被某一个 Page 私有化。
