# 05.3｜多选与批量命令

A 级真机确认 Today 的多选是独立 Interaction Mode，而不是 Todo 数据字段。

进入后：

* Row 右侧出现 selection controls；
* 选中 Row 使用非常轻的蓝色 selected background；
* 底部出现浮动批量 Toolbar；
* 主操作包括时间、Move、Delete、More；
* More 中可见 Complete、Tags、Deadline、Duplicate、Share 等；
* 批量 Delete 有数量确认；
* 退出 Selection 后恢复普通 Checkbox 交互。

推荐：

```
SelectionController
selectedIds: Set<EntityId>
mode: inactive | active
```

批量操作应发送 Batch Command，不循环调用 UI click。
