# 05.6｜完成、取消、删除与 Logbook

`Complete / Cancel / Delete` 是三个不同产品意图。

* Complete：任务做完；
* Cancel：明确不再做；
* Delete：移除对象；iPhone 当前没有可浏览 Trash，不应把 Delete 偷换成 Cancel；
* Logbook：closed items 的历史 Projection，不是把对象序列化成死文本。

A 级 Logbook 行为确认 Complete、Uncomplete、Delete 为不同动作；Uncomplete 后保留同一 domain identity。

内部为了同步可靠性可以使用 tombstone，这是 E 级实现方案，不代表 UI 必须提供 Trash。
