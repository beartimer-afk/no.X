# 05.2｜When、This Evening、Deadline 与 Reminder

When 是 Start 语义编辑入口；Deadline 是另一条独立时间约束，两者不能合并成一个“日期字段”。

## When

应支持至少 Today、This Evening、Tomorrow/具体日期、Anytime、Someday 等产品语义。选择后发出 Domain Command，并由所有 Projection 重新计算 membership。

## This Evening

是 Today 内的 presentation bucket，不能作为独立 parent，也不按固定时钟自动触发。

## Deadline

A 级录屏确认 Deadline Picker 独立存在，Deadline Today 可与 Today / This Evening 同时存在；多选也支持批量设置 Deadline。

## Reminder

Reminder 与 Start 语义协调。UI 组件只提交用户选择，不直接构造平台通知；通知调度属于 Application/Platform Service。
