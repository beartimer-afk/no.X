# 05.1｜Todo 原地展开与编辑连续性

Todo 不走普通 `List → Detail Route`。用户点击 Row 后，同一个对象在当前位置扩展为编辑 Surface，后续列表内容向下让位。

关键连续性：

```
Collapsed
→ Expanding
→ Expanded Idle
→ Editing Title / Notes / Checklist
→ Collapsing
→ Collapsed
```

Route 不变、todoId 不变、列表上下文不变、滚动上下文尽量保留。

Checkbox 点击与 Row 展开必须隔离。键盘出现时由页面/KeyboardCoordinator 使用系统 avoid-area 调整 scroll，组件不能硬编码键盘高度。
