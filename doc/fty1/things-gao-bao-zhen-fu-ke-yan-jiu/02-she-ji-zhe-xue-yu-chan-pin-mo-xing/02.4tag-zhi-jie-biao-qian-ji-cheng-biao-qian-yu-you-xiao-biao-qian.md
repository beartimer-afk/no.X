# 02.4｜Tag：直接标签、继承标签与有效标签

官方行为证明 Area / Project 可直接拥有 Tag，其中 Todo 在搜索和过滤时继承这些上下文 Tag，但继承 Tag 不应该伪装成 Todo 自己直接添加的标签。

因此必须区分：

```
directTags(entity)
inheritedTags(todo)
effectiveTags(todo) = directTags ∪ inheritedTags
```

## 为什么不能复制写入

如果 Project Tag 被批量复制到每个 Todo：

* 修改 Project Tag 会造成批量写放大；
* Todo UI 无法知道哪些标签是继承来的；
* Move Todo 后旧 Tag 很难正确撤销；
* 搜索语义与编辑语义会混乱。

推荐在查询时计算 effectiveTags，或维护带来源的派生索引。

## Tag 是横向关系

Tag 是 many-to-many context，不参与 Area → Project → Todo 层级 Parent。Tag Filter 应实现为：

```
CurrentProjection ∩ effectiveTags contains selectedTag
```

过滤不会改变对象归属。
