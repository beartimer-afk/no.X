# 02.3｜Start、Today、Upcoming 与 Deadline

## Start 是“何时进入注意力”

Start 不能简化成 nullable date。产品语义至少有：

```
StartMode = OnDate | Anytime | Someday
```

* `OnDate(date)`：在某个日期进入注意力；
* `Anytime`：现在已经 active；
* `Someday`：明确休眠，不属于当前 active 集合。

因此 Someday 绝不能等价为 `startDate = null`，因为 Anytime 也可能没有具体日期。

## Today 是 Projection

Today membership 可以来自 Start、Deadline、Repeat copy 等多个来源。Todo 的真实 Parent 不改变。

Today 与 Anytime 并非天然互斥：active 的 Today Todo 仍可能满足 Anytime 语义，这进一步证明系统列表不是实体 Folder。

## This Evening

官方参数提供 Evening 布尔语义，并且只在 Start Date 为 Today 时有意义。高置信模型：

```
Start = OnDate(today)
evening = true
```

UI 将其投影到 Today 的 This Evening Section。禁止按 18:00 自动推导，也不能把它当 Reminder。

## Deadline 是独立约束

Deadline 回答的是“最晚何时完成”，Start 回答“何时进入注意力”。二者正交，一个 Todo 可以 Anytime + Future Deadline。

## Reminder

产品语义更接近 Start Date 的附属时间提醒，而不是任意独立通知时间。跨平台内部可以使用 `reminderAt`，但 Presenter 必须保持其与 Start 语义的一致性。
