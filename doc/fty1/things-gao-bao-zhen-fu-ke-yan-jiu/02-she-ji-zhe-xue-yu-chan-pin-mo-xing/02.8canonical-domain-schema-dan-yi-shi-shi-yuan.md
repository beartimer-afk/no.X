# 02.8｜Canonical Domain Schema｜单一事实源

本页是 V1 Domain 的字段级事实源。其他页面可解释语义，但不得创建与本页冲突的第二套字段定义。

## 核心枚举

```ts
export enum LifecycleStatus { Open, Completed, Canceled }
export enum StartMode { OnDate, Anytime, Someday }
export enum EntityType { Todo, Project, Area, Heading, ChecklistItem, Tag }
```

## Todo

```ts
export interface Todo {
  id: string
  title: string
  notes: string
  lifecycle: LifecycleStatus
  completedAt?: string
  canceledAt?: string
  isLogged: boolean

  parentType?: 'project' | 'area'
  parentId?: string
  headingId?: string

  startMode: StartMode
  startDate?: string          // LocalDate，仅 StartMode=OnDate
  evening: boolean           // 只有 Today 语义下可生效，不是固定 18:00
  deadline?: string          // LocalDate，与 Start 正交
  reminder?: ReminderSpec    // 绑定 Start 语义，不绑定 Deadline

  directTagIds: string[]
  repeatSeriesId?: string
  repeatOccurrenceKey?: string

  createdAt: string
  updatedAt: string
}
```

不保存：`isToday / isUpcoming / isAnytime / isOverdue / effectiveTags / inheritedTags / selected / expanded / dragging`。这些全部是 Projection 或 UI State。

## Project

```ts
export interface Project {
  id: string
  title: string
  notes: string
  areaId?: string
  lifecycle: LifecycleStatus
  isLogged: boolean
  startMode: StartMode
  startDate?: string
  deadline?: string
  directTagIds: string[]
  rank: string
  createdAt: string
  updatedAt: string
}
```

Project 不允许嵌套 Project。Progress 是 Query 派生值，不写入 Domain。

## Area

```ts
export interface Area {
  id: string
  title: string
  directTagIds: string[]
  rank: string
  createdAt: string
  updatedAt: string
}
```

Area 没有 Completed/Canceled lifecycle。`collapsed` 是 Presentation Preference。

## Heading

```ts
export interface Heading {
  id: string
  projectId: string
  title: string
  rank: string
  archived: boolean
  createdAt: string
  updatedAt: string
}
```

Heading 只属于一个 Project。Todo 的 headingId 只能引用同 Project Heading。

## ChecklistItem

```ts
export interface ChecklistItem {
  id: string
  todoId: string
  title: string
  completed: boolean
  rank: string
  createdAt: string
  updatedAt: string
}
```

ChecklistItem 不是 Todo；Notes 中的 Markdown task-list marker 也不是 ChecklistItem。

## Tag

```ts
export interface Tag {
  id: string
  title: string
  parentTagId?: string
  rank: string
}
```

`directTags` 是持久化关系；`inheritedTags` 与 `effectiveTags` 由查询计算，绝不复制到 Todo.directTagIds。

## Repeat

```ts
export interface RepeatSeries {
  id: string
  ownerType: 'todo' | 'project'
  templateEntityId: string
  mode: 'Regular' | 'AfterCompletion'
  rule: RepeatRule
  lifecycle: 'Active' | 'Paused' | 'Stopped'
  createdAt: string
  updatedAt: string
}
```

Regular 按固定 recurrence 生成 occurrence；AfterCompletion 从实际 completedAt 推导下一次。`Create Next Copy` 必须按 `seriesId + occurrenceKey` 幂等。

## ContextOrder

```ts
export interface ContextOrder {
  contextKey: string
  entityId: string
  rank: string
}
```

排序是用户数据，且与上下文相关；禁止一个全局 `sortIndex` 覆盖 Today / Project / Area / Main Lists 等不同视图。

## ReminderSpec

```ts
export interface ReminderSpec {
  mode: 'AtTime' | 'RelativeToStart'
  localTime?: string
  offsetMinutes?: number
}
```

## Projection 输出

Projection 返回 Presentation-friendly ID/ordering 集合，不改变父子关系：`InboxQuery / TodayQuery / UpcomingQuery / AnytimeQuery / SomedayQuery / LogbookQuery / AreaQuery / ProjectQuery / DeadlineQuery / RepeatingQuery`。

## Command 边界

UI 不直接 mutate Domain。必须通过 Command，例如：`CompleteTodo / UncompleteTodo / CancelTodo / DeleteTodo / SetWhen / ClearWhen / SetDeadline / ClearDeadline / SetReminder / SetTags / MoveTodo / MoveProject / MoveHeading / ReorderChecklist / CompleteProject / CancelProject / DeleteArea / CreateNextCopy / PauseRepeat / ResumeRepeat / StopRepeat`。

## 不变量

1. Start 与 Deadline 正交。
2. Someday 是显式 StartMode，不是 null。
3. Today / Upcoming / Anytime 是 Projection，不是 parent/status。
4. This Evening 是 Today 内部 Presentation bucket，不是 route、不是 reminder。
5. direct / inherited / effective tags 必须分离。
6. Complete / Cancel / Delete / IsLogged 必须分离。
7. Heading 不是 Todo 特殊类型。
8. ChecklistItem 不是 Todo。
9. Selection / expanded / dragging 全部是 UI State。
10. 任何 3B 任务不得修改本页 Schema，除非 Task Capsule 明确写 `SCHEMA_CHANGE_ALLOWED=true`。
