# 02.6｜Projection、排序与 Command

## 系统列表是 Query

推荐统一表达：

```
InboxQuery
TodayQuery
UpcomingQuery
AnytimeQuery
SomedayQuery
LogbookQuery
DeadlinesQuery
RepeatingQuery
TomorrowQuery
```

页面拿到的是 Projection，不是新的实体集合。

## 排序是用户数据

Things 允许 Project、Today、Main Lists、Checklist 等不同上下文手工排序。同一个 Todo 在 Project 和 Today 中可能拥有不同顺序，因此一个全局 `sortIndex` 不够。

E 级建议：

```
ContextOrder(
  contextType,
  contextId,
  entityId,
  rank
)
```

## Move 是 Command

Move Todo 不只是 `parentId = target`，还可能需要：

* 校验目标类型；
* 清除不再合法的 Heading；
* 更新 context order；
* 更新 inherited/effective tags；
* 使对象从当前 Projection 消失或进入新 Projection。

因此必须通过领域 Command 完成。

## UI State 与 Domain State 分离

`expandedTodoId`、multi-selection、dragging、activeOverlay、keyboardFocus 都是 UI transient state，不写进 Todo 实体。
