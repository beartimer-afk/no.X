# 02.5｜Repeat：Template / Series / Copy

重复任务不能只保存一条 recurrence string 然后每次实时算 UI。当前产品行为已经表现出明确的“规则模板 + 可执行副本/Occurrence”分层。

## 两类规则

* **Regular**：固定日历节奏，与上一次完成时间无关；未完成时可能积累；
* **After Completion**：下一次日期 = 本次真实完成时间 + interval。

## Copy 与 Template 分离

当前执行中的 Copy 可以被重新安排；规则模板仍然决定未来。对一次 Copy 的 reschedule 必须区分：

* 只修改本次例外；
* 更新系列规则。

## Create Next Copy

这是预先 materialize 下一 occurrence，不是 Duplicate。必须有 series + occurrence identity，重复点击保持幂等。

## Pause / Resume / Stop

* Pause：保留 Series、Template 和历史，只暂停未来生成；
* Resume：恢复同一 Series；
* Stop：停止重复/将模板退出重复生命周期，不等价于删除历史。

## Deadline 与提前出现

官方示例支持一个重复项目在 Deadline 前若干天提前进入视野，因此 Repeat Template 至少要能表达目标 Deadline 与 appearance/start offset 两个时间点。

## 工程建议

```
RepeatSeries
RepeatRule
OccurrenceIdentity
TodoCopy / ProjectCopy
InstanceOverride
SeriesLifecycle
```

Repeat Engine 属于共享 Domain 层，不能散落到 TodayPage / UpcomingPage。
