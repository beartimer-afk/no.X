# 02.2｜核心领域实体与关系

## 实体

核心实体至少包括：`Todo`、`Project`、`Area`、`Heading`、`ChecklistItem`、`Tag`、`RepeatTemplate/Series` 与 `Occurrence/Copy`。

## 组织关系

```
Area
├─ Project
│  ├─ Heading
│  │  └─ Todo
│  └─ Todo
└─ Todo
```

关键约束：

* Area 可以直接含 Project，也可以直接含 Todo；
* Project 可以属于一个 Area 或不属于 Area；
* Project 不能嵌套 Project；
* Heading 必须且只属于一个 Project；
* Todo 的 Heading 必须属于它当前的 Project；
* ChecklistItem 属于 Todo，但不是完整 Todo。

## Parent 与页面上下文必须分离

一个真实 parent 为 Project A 的 Todo 可以同时在 Today、Tag Filter、Quick Find 中出现。`presentationContext = Today` 不能把 `domainParent` 改成 Today。

## 生命周期

对象状态至少是：`Open / Completed / Canceled`。`Delete` 是独立命令；`Is Logged` 也不应和 status 混为一谈。

## Project 关闭

官方接口证据支持 Project Complete / Cancel 会级联 child Todos，因此这必须是领域 Command，而不是 UI 直接写 `project.status`。

推荐：

```
completeProject(projectId)
cancelProject(projectId)
deleteProject(projectId)
```

三者语义不可合并。
