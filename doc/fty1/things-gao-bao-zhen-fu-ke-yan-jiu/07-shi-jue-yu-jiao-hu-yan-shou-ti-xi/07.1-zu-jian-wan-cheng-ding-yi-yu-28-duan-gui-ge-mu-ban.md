# 07.1｜组件完成定义与 28 段规格模板

## 完成定义

组件只有同时满足以下条件才是 `VERIFIED`：

1. Structure 正确；
2. Geometry 正确：width / height / padding / margin / gap / baseline / icon box / hit target；
3. Visual 正确：color / opacity / radius / stroke / shadow；
4. Typography 正确：family / size / weight / lineHeight / baseline / overflow；
5. State 正确；
6. Interaction 正确：tap / long press / drag / swipe / focus / keyboard / overlay。

代码存在只代表 `IMPLEMENTED`。

## 每个正式组件规格固定 28 段

1. Component purpose
2. Pages used
3. Domain / Presentation boundary
4. ArkUI structure tree
5. Layout
6. Width / Height
7. Padding / Margin / Gap
8. Typography
9. Color
10. Icon
11. Radius / Divider / Shadow
12. State Matrix
13. Interaction
14. Gesture arbitration
15. Motion
16. Keyboard / Focus
17. Data Props
18. Event / Command API
19. Accessibility
20. Safe Area / Responsive
21. Fixture
22. Golden Screenshot
23. Geometry Anchors
24. Visual Diff Acceptance
25. Interaction Test Script
26. Evidence Level
27. Pending Calibration Tokens
28. Product rules model must not change

低能力模型必须按小任务实现这些段落，不能收到一句“把 TodoRow 做得像 Things”。
