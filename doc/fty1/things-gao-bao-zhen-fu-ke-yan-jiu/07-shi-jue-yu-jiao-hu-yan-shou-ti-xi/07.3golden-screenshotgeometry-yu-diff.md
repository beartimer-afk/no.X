# 07.3｜Golden Screenshot、Geometry 与 Diff

## 两类 Golden

1. **Things Reference**：iPhone 真机证据，用于建立目标；
2. **Harmony Accepted Golden**：鸿蒙实现通过人工/自动校准后冻结，用于后续 Regression。

Golden 不能因为测试失败就自动覆盖，否则测试会失去意义。

## Geometry Anchors

组件规格必须定义命名 Anchor，例如 TodoRow：

```
A1 row left
A2 checkbox center
A3 title baseline
A4 metadata baseline
A5 trailing right
```

失败报告应输出 `checkbox center +3vp`，而不是“感觉偏右”。

## iPhone 与 HarmonyOS 不做整屏硬 Pixel Diff

两平台系统栏、屏幕比例、字体 rasterization 不同。正确做法：

* 对内容区域归一化；
* Geometry 单独 hard gate；
* Token 单独 hard gate；
* 文本区域使用字体容差/Mask；
* 图形与非文本区域做高精度 Diff；
* shadow / antialias 使用合理软容差。

## 错误优先级

P0 Structure → P1 Geometry → P2 Typography → P3 Color → P4 Motion。
