# 07.4｜Token 保证：颜色、尺寸与字体

## Color

组件禁止猜 Hex。单一 Color Token 源至少包括：

```
background.primary
background.overlay
text.primary
text.secondary
text.tertiary
accent.primary
accent.selectedBackground
status.deadline
status.destructive
divider
checkbox.stroke
checkbox.fillCompleted
```

无法可靠测量时：`value = Pending / CALIBRATION_REQUIRED`，模型不能填一个“差不多”的颜色。

## Size / Spacing

业务组件禁止散落 magic number。TodoRow、Heading、Overlay、MagicPlus 等全部使用 Size / Layout Token。

校准一个 Token 后，应同时修正所有依赖组件，而不是批量手改页面。

## Typography

至少维护 pageTitle、sectionTitle、todoTitle、todoMetadata、projectTitle、overlayRow、caption 等语义级别。每个 Token 包含 fontSize(fp)、weight、lineHeight、letterSpacing、maxLines、overflow、baseline/alignment。

字体文件本身不是复刻目标；渲染节奏、视觉层级和 baseline 才是。
