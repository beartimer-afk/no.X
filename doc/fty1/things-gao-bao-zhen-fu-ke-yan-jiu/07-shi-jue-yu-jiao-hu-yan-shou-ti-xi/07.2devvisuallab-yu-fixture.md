# 07.2｜DevVisualLab 与 Fixture

每个组件必须能够脱离真实业务数据，在固定场景中独立渲染。

## DevVisualLab

建议开发环境包含：

```
FoundationTokensPage
TodoCheckboxGallery
TodoRowGallery
MetadataGallery
ExpandedTodoGallery
ChecklistGallery
HeadingGallery
ProjectRowGallery
AreaRowGallery
OverlayGallery
PickerGallery
SelectionGallery
DragPreviewGallery
FullPageGallery
```

## Fixture 原则

测试数据由规格固定，AI 不临时发明。TodoRow 示例：

* normal；
* longTitle；
* today；
* deadline；
* repeat；
* completed；
* selected；
* expanded。

打开同一 Fixture，每次得到相同 title、metadata、scroll、keyboard、selection、overlay 状态。

## 为什么必须做

如果每次需要人工在 App 中创建 Todo、设 Deadline、加 Repeat 才能截图，任何模型或 CI 都无法稳定复现错误，也无法做长期回归。
