# 07.8｜核心验收场景目录

除了视觉 Golden，还必须存在产品语义验收。

## 组织与 Projection

* Project A 中 Todo 设置 Today 后：Parent 仍是 Project A；
* 从 Today 修改 Todo title：Project 页面看到同一对象更新；
* Group by List 只改变 Today presentation，不改变 parent；
* Move Todo 到 Project B 后，不合法的旧 Heading 必须被处理。

## Start / Deadline

* Anytime + future Deadline 合法；
* Today + Deadline Today 合法；
* Today + This Evening + Deadline Today 可共存；
* Someday 是显式状态，不因 date=null 自动产生。

## Tags

* Project/Area inherited Tag 能影响过滤；
* inherited Tag 不显示为 Todo direct Tag；
* Move 出父级后旧 inherited Tag 消失。

## Repeat

* Regular 与 completion time 解耦；
* After Completion 下一周期以真实 completedAt 为基准；
* Instance reschedule 不得默认篡改未来规则；
* Create Next Copy 幂等；
* Pause 保留 series/history；Resume 使用同一 series；Stop 不删除历史。

## Lifecycle

* Complete / Cancel / Delete 是独立命令；
* Project Complete / Cancel 具有 child cascade；
* Logbook Uncomplete 恢复同一 identity。

## UI State

* Checkbox click 不触发 Todo expand；
* Expand 不创建新 Route；
* Multi-selection 不写进 Domain Todo；
* Dragging 不在 gesture 开始时提前写数据库；drop 成功才提交 Domain Command。

## Visual

* 所有 VERIFIED component 的 geometry / token / golden regression 通过；
* 页面 safe area、keyboard、overlay、scroll fixture 通过；
* PENDING Motion/Visual 项不得伪装为精确复刻。
