# 07.6｜Motion、手势与真机验收

静态模拟器截图解决不了所有问题。Expand、Drag、Complete、Overlay 等需要独立 Motion Script。

每个 Script 至少记录：

* trigger threshold；
* start frame / end frame；
* displacement；
* scale；
* opacity；
* haptic；
* final mutation。

未知 duration / curve 不猜，使用 `PendingMotionToken`。

HarmonyOS 模拟器适合静态 Golden、Geometry、状态切换和大部分 Interaction Test；最终 haptic、真实手势手感、复杂动画帧序列仍需真机录屏校准。
