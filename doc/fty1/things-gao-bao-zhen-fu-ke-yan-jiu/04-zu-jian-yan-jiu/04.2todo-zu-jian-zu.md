# 04.2｜Todo 组件族

核心组件：

```
TodoCheckbox
TodoRow
TodoMetadata
ExpandedTodo
TodoTitleEditor
NotesEditor
Checklist
ExpandedActionBar
```

TodoRow 是 collapsed presentation；ExpandedTodo 是同一实体的 expanded presentation，不是另一张详情卡。

TodoMetadata 进一步拆 InlineSuffix、SecondaryLine、Trailing，避免 Deadline、Repeat、Parent、Reminder 各自抢布局。

每个子组件都必须先独立 Fixture + Golden PASS，再组合回 TodoRow 做 regression。
