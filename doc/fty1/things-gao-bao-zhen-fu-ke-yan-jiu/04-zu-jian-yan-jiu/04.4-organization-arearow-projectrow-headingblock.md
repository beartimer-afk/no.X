# 04.4｜Organization：AreaRow、ProjectRow、HeadingBlock

## AreaRow

表现长期责任领域及展开/折叠入口；collapse 是 UI state。

## ProjectRow

表现 Project 的 title、状态与必要 metadata；不能把 Project 简化成 TodoRow 的皮肤，因为它存在 children 和 lifecycle command。

## HeadingBlock

Heading 是 Project-scoped structural component。它拥有 stable identity，并承载一组 child Todo 的视觉分区。

Move / Archive / Convert / Delete 属于 Heading Command，不写进 Heading view 自身。完整 group drag preview 与 motion 仍待 A 级补证。
