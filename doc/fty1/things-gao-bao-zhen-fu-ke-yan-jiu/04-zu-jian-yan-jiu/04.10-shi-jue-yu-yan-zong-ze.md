# 04.10｜视觉语言总则

Things Light Mode 的总体视觉是**安静、平坦、内容优先**，复杂能力隐藏在渐进交互里。

## 已冻结方向

* 背景以白/近白为主；
* TodoRow 不使用 Card、Shadow、Divider；
* metadata 明显弱于 title；
* Deadline 是少数高注意力状态色；
* 完成态通过 Checkbox + title 弱化表达，当前证据不支持擅自加删除线；
* ExpandedTodo 才出现轻微 surface / radius / shadow，以表现编辑层级；
* 图标总体细、克制，不用厚重 filled Material icon 替代；
* Page chrome 低，留白本身承担 section 分隔。

## 数值原则

录屏测得的 epx 只用于 C 级比例 Seed。HarmonyOS 的 vp/fp 最终值必须在固定模拟器、Token Gallery 和 Golden 中校准。

## 禁止“优化”

禁止为了现代感擅自增加玻璃材质、渐变、胶囊标签、大圆角卡片、明显分割线和复杂阴影。这些即使符合某些 HarmonyOS 风格趋势，也会破坏 Things 的视觉语义。
