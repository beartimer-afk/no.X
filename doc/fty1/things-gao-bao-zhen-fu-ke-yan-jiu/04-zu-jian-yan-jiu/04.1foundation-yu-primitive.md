# 04.1｜Foundation 与 Primitive

Foundation 包括 Typography、Spacing、ColorTokens、MotionTokens、IconTokens、Radius、HitTarget、SafeArea。

Primitive 建议包括 Checkbox visual primitive、Divider、Button、IconButton、TextField wrapper、Panel/Surface 等。

Things 并不需要大量视觉 Primitive：越底层越应该稳定、克制、可自动验收。

业务组件禁止散落 literal color / font size / radius / spacing；任何校准优先修改 Token。
