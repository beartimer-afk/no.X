# 04.7｜SelectionController 与 BatchActionBar

Selection 是全局 Interaction State：

```
SelectionController
├─ active
├─ selectedIds
└─ selectionContext
```

Row 只根据 Props 渲染 selected background / control，不保存 `isSelected` 到 Todo。

BatchActionBar 根据选中集合和实体类型生成可用命令。A 级真机已确认 time / move / delete / more，以及 Complete、Tags、Deadline、Duplicate、Share 等批量能力。

删除数量确认属于 Command confirmation，不由 Row 负责。
