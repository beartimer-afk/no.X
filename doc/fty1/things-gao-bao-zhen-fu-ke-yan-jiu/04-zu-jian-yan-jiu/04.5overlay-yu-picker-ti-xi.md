# 04.5｜Overlay 与 Picker 体系

推荐统一：

```
OverlayHost
ThingsPanel
WhenPicker
DeadlinePicker
ReminderPicker
TagPicker
MovePicker
RepeatEditor
ActionMenu
```

OverlayHost 负责层级、背景、safe area、dismiss 和 route context；具体 Picker 只负责自己的语义选择。

WhenPicker 不能顺便修改 Deadline；DeadlinePicker 不计算 Todo membership；MovePicker 只返回 target intent；RepeatEditor 只编辑规则/Series，不在 View 中直接生成 copy。

Picker 的圆角、row height、overlay inset 等全部 Token 化并进入 Golden。
