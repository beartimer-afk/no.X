# 03.9｜特殊列表：Deadlines、Repeating、Tomorrow、All Projects

特殊列表是 Query，不是用户可 Move 进入的 Parent。

## 已知列表

* Tomorrow；
* Deadlines；
* Repeating；
* All Projects；
* Logged Projects。

## Deadlines

按 Deadline 聚合对象。Deadline mutation 自动改变 membership。Deadline overdue 的精确视觉、完整 Deadlines 页面仍属于 A 级补证项。

## Repeating

主要呈现具有 Repeat Template / Series 的对象及其管理入口。不能把模板管理和当前可执行 Copy 混成一个 Todo。

## All / Logged Projects

是 Project 查询维度，不产生新的 parent relation。

这些页面首版可通过统一 `SystemListPage + QueryDescriptor` 实现，但特殊 section builder 和 row presentation 应允许各自覆盖。
