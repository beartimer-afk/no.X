# 03.2｜Inbox

Inbox 的核心语义是“已捕获、尚未完全归位/澄清”。它属于组织维度，不等价于 StartMode。

因此技术模型不应把 `Inbox` 塞进 `Start = Today/Anytime/Someday` 的枚举里。更合理的设计是组织归属与时间语义正交。

## 页面能力

* 展示未归位 Todo；
* Todo 仍使用统一 TodoRow / ExpandedTodo；
* 通过 Move / Project / Area 等操作完成组织；
* When / Deadline 等时间操作仍可独立发生。

## 待验证

`Inbox Todo + Start Today` 是否仍保留 Inbox membership 是原研究中的实机验证项。没有 A 级证据前，查询规则不要写死成互斥。
