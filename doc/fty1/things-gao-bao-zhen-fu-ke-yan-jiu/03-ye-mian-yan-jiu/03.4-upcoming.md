# 03.4｜Upcoming

Upcoming 是未来承诺时间线，不是一个可以 Move 进去的 Folder。

## Query

至少受到 future Start、future Deadline、future Repeat occurrence 的影响。页面以日期 Section 组织未来对象。

## 原地展开

A 级录屏明确显示 Upcoming 中点击 Todo 后，Todo 在当前日期 Section 原位置展开，下面内容向下让位；不是 push 到 Detail Page。

## Repeat

Upcoming 是观察 Repeat copy / instance 的重要页面：当前 copy 的改期与模板更新必须分开处理。

## Page Fixture 建议

* Tomorrow 2 条；
* Day +2 1 条；
* 一个空日期节奏；
* 一个 repeating copy；
* 一个展开 Todo。

页面 Golden 需要同时验证日期标题、row rhythm、scroll、expanded surface 与 Overlay。
