# 03.5｜Anytime 与 Someday

这两个页面最容易被错误实现为“有日期 / 没日期”。

## Anytime

代表当前 active、可行动且不被未来 Start 阻挡的对象。Today item 与 Anytime membership 可以重叠，因此不能用互斥 Folder 模型。

## Someday

代表明确休眠/暂不承诺的对象。Someday 是显式 Start 语义，而不是 `date == null`。

## 页面实现

两页都使用统一 Projection + TodoRow；切换 When 会触发跨页面 membership 更新。Page 不直接修改 parent，不自行删除 Row，只观察 Query 结果变化。
