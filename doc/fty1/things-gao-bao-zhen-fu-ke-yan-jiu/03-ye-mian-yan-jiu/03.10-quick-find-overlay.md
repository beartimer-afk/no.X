# 03.10｜Quick Find Overlay

Quick Find 属于全局 Overlay 层而不是普通 Page Route。

它承担两类任务：

1. 导航寻址：System List、Area、Project、Tag、Heading 等；
2. Continue Search：进一步搜索 Notes、Checklist、Logbook 等深层内容。

## 架构

```
QuickFindOverlay
├─ QueryInput
├─ FastNavigationResults
└─ DeepSearchResults / Continue Search
```

Overlay 打开时保留底层 route context；关闭后应回到原页面。选择导航目标才发生 route mutation。

搜索索引建议拆 NavigationIndex 与 ContentIndex，以保证输入反馈足够快。
