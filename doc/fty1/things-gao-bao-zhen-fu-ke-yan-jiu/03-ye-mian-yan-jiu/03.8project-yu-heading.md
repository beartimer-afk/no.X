# 03.8｜Project 与 Heading

Project 是有终点的结果型容器，生命周期支持 Open / Completed / Canceled，并与 `Is Logged` 分离。

## Project 内容

Project 内可以有 loose Todos 与 Headings；Heading 是稳定结构实体，不是 `Todo.isHeading`。

## Heading

A 级录屏确认 Heading 可创建、选择，并通过 Move 迁移。官方行为还支持 Archive、Convert to Project、Delete 等结构命令。

Heading Move 到另一个 Project 时应迁移其 child Todos；Delete Heading 删除其 children 是当前官方语义，因此属于需要明确确认的 destructive command。

## Project 关闭

Complete / Cancel / Delete 必须是不同 Domain Command。官方接口表明 Complete / Cancel 会级联 children。

当前 A 级缺口：Project 存在未完成 children 时点击 Complete / Cancel 的精确 iPhone 提示与流程仍未完全冻结，不能猜。

## Page Fixture

* Project Title；
* 2 个 loose Todo；
* Heading A + 2 Todo；
* Heading B + 1 Todo；
* 一个 expanded Todo；
* selection / Move 场景。
