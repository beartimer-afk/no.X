# 03.1｜Main Lists 与全局导航

Main Lists 是全局入口和组织总览，不是“所有任务”的数据库页面。

主要入口包括 Inbox、Today、Upcoming、Anytime、Someday、Logbook，以及用户的 Areas / Projects。隐藏/特殊列表可通过 Quick Find 等方式访问。

## 结构

Main Lists 的核心是系统列表入口 + Area / Project 组织结构。Area 可以折叠；Project 可归属于 Area；手工排序是用户数据。

## 交互

* 点系统列表进入对应 Projection；
* 点 Area / Project 进入对象页面；
* Area / Project 的排序变化不能影响 Todo 在 Today 等 Projection 中的顺序；
* Quick Find 是跨越 Main Lists 层级的全局寻址捷径。

## 复刻重点

不要把 Main Lists 做成 HarmonyOS 常见的设置列表：Things 依赖留白、低 Chrome、轻量图标和稳定纵向节奏，不能随意加入 Card、粗 Divider 或每行背景块。
