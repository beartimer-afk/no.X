# 03.3｜Today 与 This Evening

Today 是当前工作集，而不是 Parent。一个 Project 内的 Todo 出现在 Today 时，其 Parent 仍是原 Project。

## Membership

候选来源包括：Today Start、Deadline Today / overdue 规则、Repeat occurrence、系统 carryover 等。具体边界由统一 Projection Engine 负责，Page 不应自己拼规则。

## This Evening

This Evening 是 Today 内部的次级 Section。它由 Today + evening 状态驱动，不是独立 Route，也不是 18:00 自动切换。

A 级录屏确认 Todo 可以同时是 Today、This Evening 且拥有 Deadline Today。

## Group by List

Group by List 是 Presentation Preference，不改变 Domain Parent。Grouped Today 与 This Evening 的最终嵌套顺序仍有 A 级证据缺口，应保留 Pending，而不是模型自行决定。

## 页面 UI State

Today 还承载最完整的 Interaction Mode：Todo 展开、多选、批量 When/Deadline/Move/Delete、拖拽与 Magic Plus。
