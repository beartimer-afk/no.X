# H08｜Overlay Infrastructure

Things 的 When / Deadline / Reminder / Tags / Move / Repeat / Action Menu / Confirmation 必须建立在统一 Overlay 基础设施上，不允许每个 Picker 自己实现一套弹窗、坐标、返回与键盘逻辑。

开发顺序：

* H08-A｜OverlayHost + OverlayCoordinator
* H08-B｜ThingsPanel Surface / Overlay Row Primitives
* H08-C｜WhenPicker
* H08-D｜DeadlinePicker
* H08-E｜ReminderPicker
* H08-F｜TagPicker
* H08-G｜MovePicker
* H08-H｜RepeatEditor
* H08-I｜Confirmation / Action Menu Regression

所有任务继续遵守 H00 Visual Acceptance 与 3B Task Capsule 纪律。
