# H10｜Page Composition

页面只负责 Query/Projection + 已验证组件组合 + 页面级 interaction state。页面不得成为第二套 Domain。

统一模板：Route / Query / Fixture / Layout Tree / Safe Area / Header / Sections / Component Mapping / Empty State / Overlay routing / Selection / Drag / Keyboard / Scroll restore / Cross-view mutation / Golden states / Geometry anchors / Motion scripts / Pending evidence。

子规格覆盖 Main Lists+Inbox、Today、Upcoming、Anytime+Someday、Area+Project、Logbook+QuickFind+special lists。
