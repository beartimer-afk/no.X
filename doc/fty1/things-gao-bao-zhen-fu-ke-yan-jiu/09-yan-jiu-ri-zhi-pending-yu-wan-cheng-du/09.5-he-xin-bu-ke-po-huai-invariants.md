# 09.5｜核心不可破坏 Invariants

后续任何模型和实现都必须通过这些产品不变量：

1. 系统列表是 Projection，不是 Parent；
2. Parent / Start / Deadline / Status / Tags 是不同维度；
3. Someday 是显式语义，不是 `date=null`；
4. Today 与 Anytime 可重叠；
5. This Evening 是 Today 子状态，不是固定时钟；
6. Deadline 与 Start 独立；
7. inherited Tag 不写成 direct Tag；
8. Project Complete / Cancel 是级联 Command；
9. Complete / Cancel / Delete 不合并；
10. Repeat 使用 Template / Series / Copy 思维；
11. 手工排序是持久化用户数据，并且 context-specific；
12. Todo 展开是 Presentation State，不是独立 Domain Object；
13. Multi-select / Drag / Overlay / Keyboard Focus 都是 UI transient state；
14. Heading 是稳定 Project-scoped entity；
15. Verified Primitive 不能被 Page 私自覆盖视觉值。
