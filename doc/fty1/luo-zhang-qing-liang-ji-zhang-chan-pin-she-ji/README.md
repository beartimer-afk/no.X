# 落账｜轻量记账产品设计

> 版本：0.1 · 工作名：落账 · HarmonyOS 首版设计 · 更新日期：2026-09-09

## 一句话定位

一款轻量、清爽、以手动记账为核心的个人记账 App。Outlook + 招商银行邮件导入只是补充录入方式，不改变原本的手动记账产品结构。

## 已确认的核心原则

* **手动记账是主入口。** 不连接邮箱，也能完成记账、修改、查账和统计。
* **邮件只减少部分录入工作。** 邮件记录与手动记录进入同一本账、同一套统计和同一详情页。
* **分类失败不是导入失败。** 金额、日期和收支方向可信时先入账，分类记为“待分类”。
* **用户纠错优先。** 可只修改当前记录，也可保存“以后这个商家都这样分类”的个人规则。
* **本地优先。** 账本、分类规则和统计在设备端工作；读取 Outlook 时才需要网络。
* **少页面、少打扰。** 主导航只有账本、统计、设置；邮件导入不占一个主页面。
