# 03｜视觉系统与最小素材拆分

## 设计基准

* 浅色主题，基准画布 390 × 844 逻辑尺寸。
* 正式鸿蒙实现使用 vp/fp；系统安全区动态读取，不能硬编码视觉稿的状态栏和手势条。
* 真机使用系统默认字体。设计预览使用 OFL 授权的 Noto Sans SC 子集。

## 设计参数

| 项目         | 规格                    |
| ---------- | --------------------- |
| 页面左右留白     | 20 vp                 |
| 列表行        | 最小高度 76 vp            |
| 触控区域       | 最小 48 × 48 vp         |
| 图标画布       | 24 × 24 vp，1.7 线宽、圆端点 |
| 分类图标底板     | 40 × 40 vp            |
| 页面标题       | 28/36 fp              |
| 区块标题       | 18/26 fp              |
| 正文         | 16/24 fp              |
| 辅助文字       | 13/20 fp              |
| 主色         | `#176B55`             |
| 正文         | `#20362D`             |
| 页面底色       | `#F5F6F2`             |
| 内容面        | `#FFFFFF`             |
| 待分类背景/文字   | `#FBF2DE` / `#8B5B15` |
| 卡片/弹层/按钮圆角 | 20 / 28 / 14 vp       |

支出使用正文深色和负号；收入使用主色和正号。待分类同时使用颜色、图标和文字，不能只依赖颜色表达状态。

## 最小素材交付原则

最小单元以“能够独立替换、复用和验收”为界：

* 32 个图标分别提供 SVG 和 1×/2×/3× PNG。
* Logo 图形、中文字标、App 图标分别存放。
* 空账本插画是单独文件。
* 14 张页面/状态稿分别输出 SVG 和 PNG。
* 14 个组件/状态分别输出 SVG 和 PNG。
* 没有把 Icon、Logo 或其他素材拼在一张大图里。

页面背景、卡片、圆角、分隔线、按钮底色和标签底色应由原生代码绘制；文字必须保持真实文本。页面 PNG 只用于开发对照，不能作为整页背景使用。

## 独立组件清单

| 组件     | 关键状态与验收                 |
| ------ | ----------------------- |
| 交易行    | 正常、待分类；金额对齐，长商家省略，整行可点击 |
| 月度汇总卡  | 有数据、零数据；支出最突出，结余计算一致    |
| 待分类提示条 | 有记录时显示；点击切换筛选；零记录隐藏     |
| 主按钮    | 默认、按下、禁用、保存中            |
| 分类选项   | 默认、选中；图标与文字一体点击，保持单选    |
| 数字键盘   | 数字、小数点、退格；最多两位小数        |
| 底部导航   | 账本、统计、设置三个选中状态          |
| 记一笔按钮  | 默认、按下；不遮挡列表末项           |
| 设置行    | 标题、说明、进入符号；整行可点击        |
| 规则作用范围 | 仅本笔、以后同商家；默认仅本笔         |
| 分类纠错弹层 | 关闭不修改，确认后更新，规则优先        |

360 vp 下仍保持 20 vp 边距和四列分类选项。大字体时列表行可增高、详情文字可换行、弹层可以滚动，不能简单缩小字体来适配。
