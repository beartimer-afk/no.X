# 11｜默认参数冻结表

> 这些值不是永远不可改，而是 v0.2 的实现默认值。后续只能通过试玩证据调整，不能在开发阶段随意改动。

## Session

| 参数                    |      默认值 |
| --------------------- | -------: |
| Quick Start 默认        |       开启 |
| Session 最大轮数          |      不限制 |
| RoundReady 时长         |     2.0s |
| Lose Reveal 独占时长      |     1.0s |
| Challenge Complete 反馈 |     0.7s |
| Next Move 出现频率        | 约每 3 轮一次 |
| 连续 Skip 降强度提示         |      3 次 |

## Bomb

| 参数              |      默认值 |
| --------------- | -------: |
| 起步绝对安全期         |     2.0s |
| 爆炸目标时窗          |   12–42s |
| 主要概率密集区         |   18–32s |
| 按住核心解锁 PASS     |     0.8s |
| PASS 后输入锁       |     0.6s |
| Fake Signal / 局 |      0–3 |
| Fake 首次允许阶段     |   25% 以后 |
| Fake 最小间隔       |     2.5s |
| Fake 与真实爆炸最小间隔  |     0.6s |
| 恢复安全期           |     1.5s |
| 爆炸主动画           | 0.5–0.9s |
| 爆炸后输入防抖         |     0.3s |

## Challenge

| 参数                  |       默认值 |
| ------------------- | --------: |
| difficulty          |       1–5 |
| 默认权重                |       1.0 |
| 已完成挑战本 Session 权重   |      ×0.1 |
| 最近禁止立即重复窗口          |       3 轮 |
| Skip 后本 Session 再出现 |         否 |
| Video 默认最大录制        |       30s |
| Challenge 卡片翻转      | 220–320ms |

## Secret Match

| 参数            |        默认值 |
| ------------- | ---------: |
| Hand-off 长按进入 |       1.0s |
| ≥10 匹配        |         正常 |
| 5–9 匹配        |     允许，轻提示 |
| 1–4 匹配        |    允许，建议补充 |
| 0 匹配          | 禁止进入随机挑战循环 |

## UI

| 参数            |       默认值 |
| ------------- | --------: |
| 基础栅格          |       4dp |
| 页面左右边距        |      20dp |
| 紧凑设备边距        |      16dp |
| 主按钮高          |   52–56dp |
| 最小触控目标        |   44×44dp |
| Challenge 卡圆角 |   24–28dp |
| 标准页面转场        | 220–360ms |
| 微反馈           |  80–180ms |

## 调参纪律

一次试玩迭代只调整一类变量，例如只改 Bomb 时长分布，不同时改 Fake 次数、触觉和视觉速度。否则无法知道体验变化来自哪里。
