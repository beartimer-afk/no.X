# 16｜首次启动与 Settings

## 1. 首次启动原则

不做传统 4–6 页功能轮播，不要求注册，不要求先创建玩家。

首次启动只需要让用户理解一句话：

> 两个人，一台手机。让它决定下一轮。

主要按钮：**开始**。

次级：**怎么玩？**

如果用户直接开始，Bomb 首次进入时再用 1 次轻教学说明按住 → PASS → 爆炸时谁拿着谁输。

## 2. 权限

首次启动不请求相机、麦克风、相册等权限。所有权限按功能触发时请求。

## 3. Settings 信息架构

### 游戏

* 默认 Challenge Pack；
* 默认难度范围：1–5，默认 1–3；
* Next Move：开 / 关，默认开；
* Secret Match 入口：显示 / 隐藏，默认显示；
* 保持屏幕常亮：游戏中自动，默认开。

### 反馈

* 声音：开 / 关，默认开；
* 触觉：跟随系统 / 开 / 关，默认跟随系统；
* Reduce Motion：跟随系统，不提供冲突的自定义强制项。

### 隐私与媒体

* Session 结束临时媒体：每次询问 / 自动删除；默认每次询问；
* 系统任务切换遮挡：固定开启，不允许关闭；
* App 私密锁：第一版可后置；一旦实现，支持系统生物识别。

### 数据

* 我的 Pack；
* 导入 / 导出（后续版本）；
* 清除本地 Session 临时数据；
* 恢复官方默认设置。

### 关于

* 版本；
* 隐私说明；
* 使用条款（发行时需要）；
* 反馈。

## 4. 本局设置

Pause Sheet 中的“本局设置”只显示与当前 Session 相关且安全修改的项：

* 声音；
* 触觉；
* Challenge 难度范围；
* Next Move 开关。

修改立即作用于下一稳定状态，不追溯改变当前已抽出的 Challenge。

## 5. 默认配置

首次安装：

* 官方基础 Pack；
* 难度 1–3；
* Bomb；
* Next Move 开；
* 声音开；
* 触觉跟随系统；
* 临时媒体结束时询问；
* Quick Start 使用上述默认值。

目标：用户即使从未打开 Settings，也能获得完整体验。
