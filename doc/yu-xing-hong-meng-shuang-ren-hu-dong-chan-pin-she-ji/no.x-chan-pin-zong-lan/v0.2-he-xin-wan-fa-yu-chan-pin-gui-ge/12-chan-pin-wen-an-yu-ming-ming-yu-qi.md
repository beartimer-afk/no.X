# 12｜产品文案与命名语气

## 1. 语气

产品文案应：短、克制、有一点神秘，不解释过度，不羞辱玩家，不装可爱。

避免网络黄梗、过度撒娇、成人网站式挑逗、儿童游戏式大喊大叫。

## 2. 核心命名

产品内部概念建议统一：

* Session：一场游戏
* Round：一轮
* Bomb：炸弹玩法（UI 可用更品牌化视觉，但功能名保持清晰）
* Challenge：挑战
* Pack：挑战包
* Secret Match：默契匹配 / 秘密匹配（最终中文名视觉阶段再定）
* Next Move：下一步 / 下一轮权力

技术文档可保留英文术语，用户 UI 优先中文自然表达。

## 3. 推荐文案

### Home

主按钮：**开始**

次级：挑战包 / 创建 / 设置

当前 Pack：**正在使用：夜间挑战**（示例）

### Privacy Gate

> 只给你看。
>
> 准备好再继续。

按钮：**我准备好了**

### Hand-off

> 已记录。
>
> 把手机交给另一位玩家。

按钮：**我是下一位**（长按）

### Match Result

> **匹配到 18 个挑战**

辅助：**只会出现你们都接受的内容。**

### Round

**ROUND 03** / 中文可显示 **第 3 轮**，最终依据品牌气质选择一种，不混用。

### Lose Reveal

优先：**是你。**

备选：**轮到你了。**

不推荐：“你输了哈哈哈”。

### Challenge Hidden

> 挑战已确定。

按钮/手势提示：**揭晓**

### Skip

首选：**换一个**

次选：**跳过**

### 连续 Skip

> 这轮不太对胃口？
>
> 可以降低一点强度。

按钮：**降低强度** / **继续随机**

### Complete

**完成**

不要“任务成功 +100”。

### Session End

> 今晚玩了 8 轮

媒体：

> 本次产生 3 个临时记录。

按钮：**全部删除** / **查看并处理**

## 4. 错误文案原则

错误必须告诉用户“现在能做什么”，而不是只解释技术原因。

例如权限拒绝：

> 暂时不能使用相机。
>
> 可以换一个挑战，或者去设置开启权限。

存储不足：

> 空间不足，无法录制这个挑战。

按钮：**换一个**。

## 5. 文案长度限制

* 主按钮：尽量 ≤6 个汉字；
* 状态标题：≤10 个汉字；
* Challenge 正文允许长，但首屏理想 ≤60 汉字；
* 错误说明尽量 ≤2 行；
* Bomb 屏幕不出现教程型长句。
