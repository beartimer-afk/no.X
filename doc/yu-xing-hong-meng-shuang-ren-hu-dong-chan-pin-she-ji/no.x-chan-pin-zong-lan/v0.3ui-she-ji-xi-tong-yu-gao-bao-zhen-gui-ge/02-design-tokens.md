# 02｜Design Tokens

> 以下为 v0.3 默认设计基线。允许在真机视觉验收后微调，但开发实现不得自行替换。

## 尺寸单位

* 布局：vp；
* 字体：fp；
* 最小触控区域：48vp × 48vp；
* 手机基准宽度：360–430vp；
* 页面水平安全留白：20vp；
* 大屏内容最大宽度：480vp，居中。

## 8vp 空间系统

基础步长 4vp，主节奏 8vp。

* 4：图标内部微间距；
* 8：紧密关联；
* 12：文字与辅助信息；
* 16：组件内部；
* 20：页面左右边距；
* 24：卡片区块；
* 32：模块间；
* 48：大段落；
* 64+：游戏舞台留白。

## 圆角

* XS：10vp；
* S：14vp；
* M：18vp；
* L：24vp；
* XL：32vp；
* Pill：999vp。

核心游戏卡片优先 28–32vp，不大量混用半径。

## 颜色：Dark 默认主题

### Background

* `BG_0 = #0B0B0D`
* `BG_1 = #111115`
* `SURFACE_1 = #17171C`
* `SURFACE_2 = #202027`

### Text

* `TEXT_1 = #F5F3EE` 暖白；
* `TEXT_2 = #AAA7A1`；
* `TEXT_3 = #6E6B68`；
* `TEXT_DISABLED = #4A4847`。

### Brand Accent

默认主强调色采用**琥珀电光**而不是粉紫：

* `ACCENT_1 = #F6B85A`
* `ACCENT_2 = #FFD58C`
* `ACCENT_DIM = rgba(246,184,90,0.14)`

理由：既有温度，又不会把产品直接标签化成情侣 / 成人 App。

### Explosion

* `EXPLOSION = #FF694A`
* 只用于 0.2–1.2 秒的爆发状态、危险确认和极少量提示。

### Success

* `SUCCESS = #78C6A3`
* 仅功能结果使用，不用于游戏主反馈。

## Core 材质

Core 不用纯色圆。推荐由三层组成：

1. 外层弱光晕：直径 240–300vp，透明度 8–16%；
2. 中层玻璃壳：160–210vp，低对比渐变；
3. 内核：80–120vp，高亮区域随状态缓慢偏移。

默认状态视觉对比低；危险程度通过脉冲速度、内核压缩、局部高光和阴影变化提升。

## 字体

使用 HarmonyOS Sans 系统字体，不内置第三方字体。

推荐层级：

* Display XL：48fp / 52，600；
* Display L：36fp / 42，600；
* Title L：28fp / 34，600；
* Title M：22fp / 28，600；
* Body L：17fp / 25，400；
* Body M：15fp / 22，400；
* Label：13fp / 18，500；
* Micro：11fp / 16，500。

数字倒计时可以使用更高字重 650–700，但禁止使用“游戏字体”。

## 阴影与光

Dark UI 不依赖传统黑色投影。优先：

* 1vp 低透明亮边；
* 内阴影；
* 局部光晕；
* 背景亮度差。

禁止每张卡片都带明显悬浮阴影。

## 模糊

只在手机交接、Secret Match 隐私遮挡和媒体预览后景中使用。普通卡片不默认 Blur。

## 图标

* 20 / 24vp 两档；
* 线宽 1.75–2vp；
* 圆端点；
* 图标颜色继承 Text 2；
* 主动作尽量不用图标+文字重复表达。
