# 01｜品牌与视觉母版

## 品牌角色

余兴不是内容平台，而是现场的第三个参与者。它应该像一个有分寸感的主持人：平时安静，关键时刻突然介入。

### 人格

* 不解释过多；
* 不卖萌；
* 不命令；
* 不羞辱；
* 不高声吵闹；
* 知道什么时候制造沉默；
* 知道什么时候给出强反馈。

## 视觉母题：Orb / Core

产品的核心视觉对象不是“炸弹”，而是一个**不稳定核心 Core**。

它可以表现为：

* 一颗悬浮的高密度能量体；
* 一个有深度的半透明核心；
* 内部存在缓慢流动和脉冲；
* 接近爆发时出现局部形变、折射和光晕收缩。

好处：

1. 不幼稚；
2. 可跨越 Bomb、Secret Match、Challenge Reveal 等场景复用；
3. 能承接 HarmonyOS 的空间感和沉浸光感语言；
4. 以后不同 Theme 只需要改变 Core 的材质，不必重做结构。

## Logo 建议

第一版不需要复杂图形 Logo。优先使用：

**余兴 / AFTERPLAY（工作名） + 一个抽象 Core 符号。**

Core 符号由两个不完全同心的椭圆 / 环构成，暗示“两个玩家 + 不确定交汇”。禁止使用心形、酒杯、炸弹、骰子作为品牌主图形。

## 品牌节奏

静态界面：80% 克制、20% 能量。

游戏高潮：短暂反转为 20% 克制、80% 能量。

这意味着大部分时间不能一直发光、漂浮、闪烁。否则高潮没有对比。

## 图形语言

* 主体优先圆 / 椭圆 / 环；
* 卡片使用连续圆角，不做尖锐赛博切角；
* 图标使用线性图标，线宽统一；
* 状态切换更多通过形变和亮度，不依赖彩色标签；
* 装饰性粒子极少，只在 Explosion 后短暂出现。

## 摄影与插画

第一版原则：**不用人物摄影作为核心 UI。**

理由：人物照片会快速把产品锁死到情侣 / 成人 / Party 某一场景，也容易廉价。产品应该靠材质和动效建立氛围。

## 品牌验收

任何一张截图单独拿出来都应该：

* 看不出是廉价成人 App；
* 看不出是儿童派对游戏；
* 看不出是系统 Demo；
* 能感受到“这里正在等待某件事发生”。
