# 04｜Bomb 静态构图

## 页面目标

用户进入页面后不需要读规则，视线必须自然落到 Core，并理解“拿着它，按住，然后传出去”。

## 纵向构图

### 顶部状态区：56vp + Safe Area

左：退出 / 暂停，视觉弱化。

中：`ROUND 03`，13fp / 500 / Text 3。

右：默认留空。不要放计时器。

### 中央舞台区：弹性高度

Core 在视觉中心略偏上 4–6%：避免底部按钮让视觉重心下坠。

标准 390vp 宽设备：

* 外光晕约 280vp；
* 玻璃壳约 196vp；
* 内核约 104vp。

小屏按宽度缩放，但内核不小于 84vp。

### 指令区

Core 下方 28–40vp：一句短提示。

Idle：`按住核心` Ready-to-pass：`传给对方`

17fp / Text 2，禁止长说明。

### 底部动作区

不做传统“PASS”大按钮。

核心本身就是主要输入区：用户长按 Core 0.8s 解锁传递。

底部只保留极弱的辅助文案 / 手势提示，避免用户一直盯底部按钮而忽略 Core。

## 触控范围

Core 视觉直径约 196vp，但有效触控范围至少 220vp；透明扩展，不改变视觉尺寸。

## 进度反馈

按住时不要出现传统圆形 Progress Ring 0→100%。那会暴露“只需等多久”的工具感。

改为：Core 内核被逐渐“压缩 / 充能”，0.8s 完成后产生一次磁吸式弹开，提示可传。

## 禁止信息

运行页绝不能显示：

* 剩余秒数；
* 爆炸概率；
* 安全阶段；
* 当前 Fake Signal 次数；
* 传递次数；
* 规则说明卡。

未知性必须由 UI 真正保护。
