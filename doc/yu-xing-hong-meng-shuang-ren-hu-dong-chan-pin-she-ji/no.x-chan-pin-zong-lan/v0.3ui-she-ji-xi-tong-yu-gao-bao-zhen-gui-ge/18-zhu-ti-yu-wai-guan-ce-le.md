# 18｜主题与外观策略

## v1 决策：品牌 Dark，而不是系统 Dark Mode

余兴核心游戏场景固定采用深色舞台，这是产品氛围的一部分，不随系统浅色 / 深色切换而彻底换肤。

原因：

* 暗背景有利于聚焦 Core；
* 现场夜间 / 室内场景更自然；
* Explosion 的亮度对比依赖暗舞台；
* 同一个 Session 不应因为系统主题变化改变情绪。

## 工具页

Packs / Editor / Settings 第一版也沿用 Dark 品牌主题，保持整体一致。

未来若做 Light Theme，必须作为完整 Theme 设计，不是简单反转颜色。

## Theme Pack 能力

未来可以把视觉皮肤做成 Pro 能力，但 Theme 只能改变：

* Accent；
* Core 材质；
* Surface 细微色相；
* 音效材质。

不能改变：

* 信息结构；
* 动效时序；
* 触控尺寸；
* Explosion 基础语义；
* Challenge Card 布局。

## 第一版主题

### Ember / 余烬（默认）

* Accent：琥珀电光；
* Core：温暖玻璃 + 高密度内核；
* 情绪：成熟、克制、略危险。

未来候选但不进入 MVP：

### Ice

冷蓝 / 银白，偏冷感。

### Violet

可以存在，但必须偏深紫矿物材质，禁止俗艳粉紫渐变。

## 系统状态栏 / 导航栏

跟随品牌深色舞台，图标使用浅色模式。切到系统权限 / Picker 时遵循系统页面。

## 截图一致性

同一 Theme 下所有页面不得各自调整 Accent 色相。Theme Token 是全局唯一来源。
