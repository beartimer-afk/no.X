# v0.3｜UI 设计系统与高保真规格

> 目标：把“余兴”的 UI 从审美偏好升级为可执行、可验收、不可随手改坏的设计系统。

## 设计结论

这个产品的 UI 不是承载功能的容器，而是核心玩法的一部分。用户真正感受到的“神秘、紧张、期待、揭晓、报复、再来一轮”，都由视觉、动效、触觉和声音共同制造。

如果只是把功能放进漂亮卡片里，产品仍然会失败。

## 视觉母题

### 关键词

**夜间、克制、悬浮、能量、呼吸、磁吸、隐秘、精致、轻危险感。**

### 禁止气质

* 廉价成人网站式紫红渐变；
* 赌场 / 夜店霓虹；
* 儿童 Party Game；
* 卡通炸弹、火焰、骷髅等直白符号；
* 大量玻璃拟态叠加；
* 系统默认组件直接堆砌；
* 满屏按钮、说明和规则文字。

## HarmonyOS 适配原则

参考 2026 HarmonyOS 最新设计方向：沉浸光感、空间层次、可变字体、物理动效和移动优先响应式布局。但余兴只借系统能力与物理逻辑，不复制系统 App 的视觉外观。

HarmonyOS Sans 作为默认字体，以可变字重制造信息层级；布局必须优先保证最小手机宽度下完整可玩，再向大屏扩展。

## UI 的五条最高原则

1. **一屏只讲一件事。**
2. **结果不要提前暴露。**
3. **关键动作必须有物理反馈。**
4. **越紧张的阶段，界面信息越少。**
5. **用户永远知道当前能做什么，但不一定知道接下来会发生什么。**

## 色彩策略

不把产品固定成“粉紫情侣 App”。默认主题采用近黑中性色作为舞台，单一高能强调色只在关键状态出现。

建议基础 Token：

* Canvas / 主背景：近黑，不使用纯 #000000；
* Surface 1：比背景高一个明度层级；
* Surface 2：用于浮层与卡片；
* Text Primary：高对比暖白；
* Text Secondary：降低对比；
* Accent：单一品牌高能色；
* Danger / Explosion：仅爆炸和破坏性操作短暂出现；
* Success：极少使用，避免工具 App 感。

颜色数必须克制。游戏中的“紧张”优先由亮度、尺度、速度和触觉变化表达，而不是不断换颜色。

## 空间原则

核心游戏页使用大留白和单视觉主体。信息从中心向边缘递减：

* 中央：当前唯一重要对象；
* 中下：当前唯一主要动作；
* 顶部：弱化的 Round / 状态；
* 边缘：退出、更多等低频操作。
