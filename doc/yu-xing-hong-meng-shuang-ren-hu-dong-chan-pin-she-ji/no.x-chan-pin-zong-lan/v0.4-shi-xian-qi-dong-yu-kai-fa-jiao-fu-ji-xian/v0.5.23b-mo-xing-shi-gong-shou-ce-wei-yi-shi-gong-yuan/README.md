# v0.5.2｜3B 模型施工手册（唯一施工源）

> 本章是 NO.X v0.1 给低推理能力开发模型使用的唯一施工源。3B 不允许同时读取 v0.4 / v0.3 / v0.2 作为实现依据。

## 目标

让约 3B 规模、容易漏要求、容易自作主张、跨上下文能力有限的开发模型，也能在**不重新做产品设计、不重新做 UI 决策、不自行找素材、不自行补规则**的前提下实现 NO.X v0.1。

## 文档设计原则

1. **重复优于引用。** 每个原子任务重复写关键颜色、尺寸、状态与禁止项。
2. **一步一验证。** 每个任务完成后必须构建并提交指定截图/录屏。
3. **不能猜。** 未定义内容必须输出 `SPEC_GAP`。
4. **不能优化。** “更符合平台规范”“我认为更好看”“顺手重构”都不是合法理由。
5. **不能提前实现。** 当前任务未要求的功能不得提前加入。
6. **不能自行找资源。** 图片、字体、图标、声音都必须来自本手册冻结规则或设计侧资源包。
7. **只能机械施工。** 开发模型只负责编码、复制资源、运行、截图、修复。

## 唯一权威规则

3B 施工时只允许使用 **v0.5.2** 中明确提供给当前任务的页面。旧版本只保留给人类查看历史，不得塞进 3B 上下文。

当前任务内部发生冲突时，优先级固定为：

`当前 TASK > 03｜状态机 > 03A｜静态资源合同 > 02｜Token > 01｜工程目录 > 00｜执行协议`

若仍无法决定：`SPEC_GAP`，不得自行折中。

## 正式开工顺序

`开工 Gate → TASK-000A → TASK-000B → TASK-001 → TASK-002 → ... → TASK-017`

Gate 未通过不得碰代码；000A/000B 未通过不得开始 Home。

## v0.1 冻结范围

只实现：

**Home → Round Ready → Bomb 按住/说话 → PASS → 对方继续 → Tension/Fake Signal → Explosion → Lose Reveal → Challenge Reveal → 下一轮。**

明确不做：Secret Match、账号、联网、多人、排行榜、媒体拍摄、录音识别、AI 内容生成、远程内容包、复杂设置、商店、付费。

## 固定平台

* HarmonyOS 手机应用
* ArkTS + ArkUI
* 竖屏优先
* 单机运行
* 静态资源来自 `NOX_static_assets_v0.1`
* 字体只使用设备系统字体，不随包分发第三方字体文件

## 完成定义

只有同时满足：核心流程连续可玩至少 5 轮、Bomb 手感/Explosion/UI 验收全部通过、正式分层 App Icon 已接入、无新增第三方素材、无新增字体文件、所有 `SPEC_GAP` 已关闭或明确延期，才算 v0.1 完成。
