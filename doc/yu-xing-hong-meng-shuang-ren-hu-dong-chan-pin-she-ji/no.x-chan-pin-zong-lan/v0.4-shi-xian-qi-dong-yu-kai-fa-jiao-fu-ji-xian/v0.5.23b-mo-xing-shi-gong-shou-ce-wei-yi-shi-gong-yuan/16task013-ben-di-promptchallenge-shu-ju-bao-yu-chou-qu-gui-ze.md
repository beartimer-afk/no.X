# 16｜TASK-013：本地 Prompt/Challenge 数据包与抽取规则

## 目标

移除之前任务中的测试硬编码，将 Prompt 和 Challenge 全部放入本地静态数据文件。v0.1 不联网。

## 依赖

TASK-012 PASS。

## 数据文件

```
data/challenges.ts
```

同时定义两类数据：`MicroPrompt` 与 `Challenge`。

## MicroPrompt 结构

```
id: string
text: string
enabled: boolean
```

## Challenge 结构

```
id: string
text: string
hint?: string
enabled: boolean
```

禁止加入开发暂时不用的复杂字段。

## Prompt 抽取规则

* 每次 Handoff 完成后抽取下一 Prompt；
* 使用均匀随机；
* 不得与上一条相同；
* 若 enabled 数据只有 1 条，允许重复；
* 不记录跨 Session 历史。

## Challenge 抽取规则

* 进入 Challenge Reveal 时生成一次 currentChallengeId；
* `下一张` 再生成一次；
* 同一回合最多连续避免最近 2 条；
* 若候选不足则允许重复；
* 不因输家身份调整内容。

## 禁止

* 网络下载；
* AI 生成；
* 远程配置；
* 内容审核逻辑；
* 数据库。

## 必交

* `challenges.ts` 内容截图/文本；
* `TASK013_prompt_random.mp4`；
* `TASK013_challenge_random.mp4`。
