# 10｜Settings / Summary / Media

## Settings 视觉原则

Settings 可以遵循 HarmonyOS 熟悉的信息架构，但必须使用余兴 Token。不要为了品牌化而重新发明 Toggle / Slider 的基本交互。

分组：

### 游戏

* 默认 Pack
* Bomb 强度
* Fake Signal
* 下一轮权力

### 感官

* 声音
* 触觉
* 减少动态效果

### 隐私

* 临时媒体处理
* 自动清理
* 应用锁（后续）

### 关于

* 版本
* 隐私说明

## Bomb 强度

不要暴露“12–42 秒”这种内部算法。

对用户只提供：

* 轻松
* 标准
* 紧张

内部映射参数。

## Session Summary

结束 Session 后页面依然克制。

顶部：`今晚到这里。`

中部最多三项数据：

* 8 轮
* 7 个完成
* 24 分钟

不要做排行榜、勋章、彩纸庆祝。

## Media Summary

如果产生临时媒体，Summary 首屏明确显示：

> 本次有 3 个临时记录

主要动作根据默认隐私策略：

* `查看记录`
* `全部删除`

如果默认是“结束即删除”，先执行删除再显示：

> 临时记录已清理

## Media Viewer

深色全屏；一次只看一个；底部只保留：

* 删除；
* 保存（如果产品允许）；
* 下一项。

进入系统后台时立即模糊 / 遮挡。

## 权限

相机 / 麦克风权限必须在用户第一次真正选择相关挑战时请求，不在首次启动请求。

拒绝权限：当前挑战可以“换一个”或使用无媒体完成方式，不能卡死 Session。

## 危险操作

“清空所有自定义 Pack / 删除所有记录”使用底部确认 Sheet；Explosion 色只用于确认按钮文字或极小区域，不大面积红屏。
