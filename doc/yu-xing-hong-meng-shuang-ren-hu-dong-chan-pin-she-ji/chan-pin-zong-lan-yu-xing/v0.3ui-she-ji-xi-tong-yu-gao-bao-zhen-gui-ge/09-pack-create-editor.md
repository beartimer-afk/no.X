# 09｜Pack / Create / Editor

## 目标

编辑器是工具页，可以比游戏页信息密，但仍必须克制。用户应能在现场 20–30 秒内创建一个临时挑战。

## Packs 首页

顶部：`PACKS`

第一块：`正在使用`，显示当前 Pack，大卡片一张。

下面：

* 官方基础包；
* 我的 Pack。

不做应用商店式横向推荐和封面瀑布流。

## Pack Card

卡片只显示：

* 名称；
* 挑战数量；
* 一个简洁材质封面；
* 是否启用。

不要显示星级、下载量、分类徽章堆叠。

## Create Challenge 快速编辑器

第一屏优先只有：

1. 挑战正文；
2. `保存`。

正文输入后下方展开可选设置：

* 执行方式；
* 限时；
* 媒体；
* 难度；
* 权重；
* 验收。

用户不碰高级设置，就使用当前 Pack 默认值。

## 输入框

不是传统矩形 Form。正文区域作为一块大纸片 / Surface：

* 最小高 144vp；
* 22fp；
* 无显眼边框；
* Focus 时仅底部 / 边缘出现 Accent 呼吸亮度。

占位文案：

> 写下一个挑战…

## 高级选项

使用 Bottom Sheet 分组编辑，不在一个页面堆十几个 Switch。

例如点“媒体”：

> 无 / 录音 / 拍照 / 视频

一次只做一个选择。

## 临时挑战

游戏中的 Next Move 可以直接打开“临时挑战”微编辑器：

* 只有正文；
* 保存即进入下一轮；
* 默认不写入永久 Pack；
* 可以二次选择“保存到我的 Pack”。

这对现场玩法非常关键。

## 删除

删除自定义挑战需要确认，但文案简单：

> 删除这个挑战？ 此操作无法撤销。

## 成人等私人内容

编辑器不提供官方成人分类、成人关键词模板或公开分发入口。用户自定义内容只作为本地数据处理。

## 验收

第一次使用的用户在没有教程的情况下，应能在 30 秒内创建并保存一个纯文本挑战。
