# 03｜Home / Start

## 设计目的

首页不是功能导航页，而是**进入现场状态的入口**。

必须做到：打开后 1 秒内知道怎么开始；3 秒内可以进入 Round。

## 构图

### 顶部 15%

左上：余兴 Logo / Wordmark，弱显示。

右上：Settings 图标，48vp 点击区，视觉 20vp。

不要放用户头像、签到、金币、通知。

### 中央 55%

一个静止的 Core，约 180–220vp。不是可点击大按钮，只负责建立氛围。

Core 下方只出现一句状态文案：

> 今晚，玩点什么？

或更克制地仅显示产品名。

### 底部 30%

主按钮：`START`

* 高 60vp；
* 宽度填满安全区；
* 圆角 30vp；
* 暖白底 + 近黑字，默认不使用 Accent 大面积填充；
* 按下时缩放到 0.985，120ms。

主按钮下方为两个文字入口：

`SECRET MATCH` · `PACKS`

Create 放进 Packs 内，不在首页平铺四个主功能。

## START 行为

点击 START：

1. Core 轻微收缩 120ms；
2. 背景亮度下降；
3. Core 吸向屏幕中心并放大；
4. 直接进入 Round Ready。

总转场控制在 450–600ms。

不要出现“选择玩家人数 / 模式 / 难度”的中间页。

## 首次启动例外

首次启动如果没有可用 Challenge Pack：自动启用官方基础包，不阻塞 START。

## 首页不能出现

* 横向 Banner；
* 内容推荐 Feed；
* 卡片宫格；
* “情侣 / 酒局 / 聚会”大入口；
* 付费促销；
* 权限请求。

## 截图验收

首页截图缩小到 25% 仍应只有三个视觉层级：

1. Core；
2. START；
3. Logo / Secondary actions。

如果能数出 6 个以上视觉焦点，视为失败。
