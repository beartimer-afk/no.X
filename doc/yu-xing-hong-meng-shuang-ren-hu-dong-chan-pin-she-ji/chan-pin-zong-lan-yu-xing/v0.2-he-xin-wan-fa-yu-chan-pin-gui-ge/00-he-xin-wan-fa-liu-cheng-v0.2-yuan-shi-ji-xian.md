# 00｜核心玩法流程 v0.2 原始基线

## 0. 核心目标

一局游戏必须完成四件事：

**制造悬念 → 产生结果 → 触发挑战 → 自然进入下一轮**

用户真正获得的不是“随机抽一道题”，而是：

> 我知道要发生点什么，但不知道什么时候发生、不知道谁会中、不知道中了以后是什么。

因此整个流程设计的第一目标不是效率，而是**情绪曲线**。

## 一、产品存在两种开局方式

### A. 快速开始 Quick Start

适合已经玩过、现场不想配置、临时打开就玩。

路径：**打开 App → START → 直接进入第一轮**。

App 自动使用当前默认 Pack、当前默认小游戏、最近一次规则、默认挑战强度。

整个过程不要询问几个人、玩家名字、当前场景、关系或是否喝酒。目标是 3 秒内进入游戏状态。

### B. Secret Match 开局

路径：**START → Secret Match → 玩家 A 私密选择 → 手机交给 B → 玩家 B 私密选择 → 生成共同挑战池 → 开始游戏**。

它是独立可选模式，不是每次必须经历的流程。

## 二、Secret Match

### Step 1：进入秘密选择

只显示：

> 给第一位玩家 其他人暂时不要看屏幕

按钮：**我准备好了**。

### Step 2：逐张判断

一次只显示一张挑战概念/内容，不做长列表。

选择：**愿意 / 可以试试 / 跳过**。

用户判断的是“今天是否愿意在游戏里遇到”，而不是长期偏好。

### Step 3：选择结束

不展示统计。显示：

> 已记录 把手机交给另一位玩家

随后页面自动遮挡。通过长按“我是下一位玩家”进入下一阶段。

### Step 4：第二位玩家

流程完全相同。最后计算双方共同接受集合，形成本 Session 的 Challenge Pool。

只显示正向结果，例如：

> 今晚匹配了 18 个挑战

不显示双方各自拒绝数量或具体拒绝项。

## 三、统一游戏循环

Quick Start 或 Secret Match 后都进入：

**READY → 游戏 → 输家 → 挑战 → 执行 → 结算 → 下一轮**

每轮控制在几十秒到约两分钟，不让流程本身拖沓。

## 四、READY

每轮开始前短暂重新聚焦注意力：

> ROUND 03 BOMB

约 2 秒后自动开始，不要求每轮确认。

## 五、Bomb

第一版不同时开发很多小游戏，先把 Bomb 做成代表玩法。

视觉主体不一定是传统炸弹，可是能量核心、脉冲圆环或即将失控的装置，避免廉价 Party Game 感。

系统生成隐藏爆炸时间，玩家不知道。手机通过呼吸动画、轻触觉、声音和随时间增加的不稳定感制造压力。

当前拿手机的人必须完成一个最小动作（如按住核心约 0.8 秒）才出现 PASS，再把手机交给对方。不能只是无限快速互传。

## 六、Bomb 悬念三阶段

### 安全感

前期稳定，让用户产生“还早”的错觉。

### 不安

出现轻微闪烁、短震和 Fake Signal，但不是真爆炸。

### 高度紧张

动画和声音密度增加，但始终不显示剩余时间、概率、进度条。

原则：**不要让玩家可以计算。**

## 七、爆炸瞬间

先瞬间停止正常动画，再触发强触觉、短促视觉裂变和音效，主动画 0.5–1 秒内结束。

随后只显示：

> **是你。**

挑战不要立刻一起出现，让“输了”这个结果独占约 1 秒。

## 八、挑战揭晓

形成第二层悬念：先显示“挑战已确定”的卡背，用户主动点击/上滑后才看到内容。

也就是：

**第一次未知：谁输 → 第二次未知：输什么。**

## 九、Challenge Card

主区域只显示挑战正文。辅助只保留必要信息：难度、限时、是否媒体任务。

不展示权重、技术标签和内部参数。

## 十、挑战执行

### 普通挑战

完成 / 换一个。

### 限时挑战

开始 → 大号倒计时 → 时间到后由现场决定完成或换一个。

### 录音挑战

开始录音 → 播放 / 重录 / 使用。

### 拍照 / 录像

App 内完成 → 使用 / 重拍。默认不自动进入系统相册。

## 十一、跳过不是失败

任何挑战永远可以跳过/换一个。

不使用“胆小鬼”“Chicken”等羞辱性表达。游戏压力来自悬念和输赢，而不是 UI 强迫执行。

## 十二、对方验收

两个人本来就在现场，所以默认不需要复杂验收。显式要求时才提供“完成 / 再来一次”。

## 十三、输家获得下一轮权力

挑战完成后可周期性出现 NEXT MOVE，例如：

* 下一轮难度 +1；
* 选择下一轮游戏；
* 从两个方向中选一个。

让输掉的一方获得一点控制权，形成：

**输 → 执行 → 获得权力 → 下一轮**。

## 十四、下一轮

不要回首页。直接：

> ROUND 04 3 / 2 / 1

继续。

目标是让人产生“再玩一轮”，而不是“再点一次开始”。

## 十五、Session 结束

Session 默认无限继续，直到主动退出。

Summary 可展示轮数、完成挑战数、跳过数、游戏时长。

若产生媒体，提示处理本次临时记录：**全部删除 / 查看并处理**。默认不保存。

## 十六、完整链路

**打开 App → START → 可选 Secret Match → ROUND READY → 小游戏产生输家 → 输家揭晓 → Challenge 卡隐藏 → 主动揭晓 → 执行/换一个 → 可选媒体 → 完成 → 可选 NEXT MOVE → ROUND+1 → 循环 → Session End → 媒体处理/Summary。**

## 十七、第一版重点投入的 8 个瞬间

1. START → 游戏开始
2. Secret Match 手机交接
3. Bomb 持续紧张过程
4. Fake Signal
5. 爆炸瞬间
6. Challenge 翻开
7. NEXT MOVE 控制权
8. 下一轮无缝开始

创建 Pack、设置、历史等管理页面第一版可以克制。

## 十八、产品节奏原则

**信息少一点 → 等待一下 → 揭晓一点 → 再制造未知 → 反馈 → 继续。**

普通工具追求快速告诉用户结果；余兴要让用户享受**结果出现之前的那几秒**。
