# 29｜开发模型禁止词与危险信号清单

如果开发模型在回复里出现以下表达，应提高警惕并检查是否擅自发挥。

## 危险表达

* “为了更好的用户体验，我……”
* “我顺便……”
* “更符合 HarmonyOS 风格……”
* “通常 App 会……”
* “我建议增加……”
* “可以考虑……”
* “我优化了……”
* “我统一重构了……”
* “为了简化……”
* “我把它改成更现代的……”

## 对应处理

只要涉及未授权行为，要求：

```
撤销规格外修改。只保留 TASK 明确要求内容。
列出撤销文件和 diff。
重新运行当前 TASK 验收。
```

## 特别危险的代码迹象

* 新增未定义依赖库；
* 引入大型 UI 框架；
* 新增全局主题系统；
* 自己添加路由层；
* 自己做 Repository/数据库；
* 新增联网权限；
* 新增相机/麦克风权限；
* 新增账号相关权限；
* 新增埋点 SDK；
* 新增广告 SDK。

发现以上任何一项，当前 TASK 直接 FAIL，除非任务页明确要求。
