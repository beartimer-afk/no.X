# 10｜响应式与 HarmonyOS 设备适配合同

## 基准

所有视觉标注基于 390×844vp。

## 宽度适配

### 360–389vp

* 左右边距从 24vp 降到 20vp；
* Core 视觉直径从 156vp 降至 146vp；
* Challenge Card 左右边距至少 22vp；
* 字号不缩小；
* Primary Button 高度保持 56vp。

### 390–430vp

* 使用基准值；
* 内容最大宽 382vp；
* 多余宽度增加外边距，不放大按钮高度。

### >430vp 手机 / 折叠外屏

* 内容最大宽 390vp，居中；
* 背景可铺满；
* Core 最大 168vp；
* 不把单列改成双列。

## 高度适配

若可用高度 <760vp：

优先减少纵向间距，顺序：

1. 标题与副标题间距 -4vp；
2. Prompt Card 与 Core 间距 -10vp；
3. 底部装饰文案隐藏；
4. 主按钮位置上移。

禁止压缩：

* Core 命中区；
* Primary Button 高度；
* 正文字号。

## 系统栏

* 状态栏内容使用浅色；
* 页面背景延伸到状态栏下；
* 导航条区域同 `bg.base`；
* 禁止出现与设计无关的系统浅色条。

## 横屏

首版锁定竖屏。禁止做横屏临时布局。

## 键盘

首版核心玩法无文本输入，不应弹键盘。

## 无障碍

* 所有可点击区域 ≥44×44vp；
* 文字与背景保证基本可读性；
* Core 不能只靠颜色表达紧张状态，必须同时有形变 / Ring 变化；
* TalkBack 文案：`按住核心。松开可传给对方。炸弹可能随时爆炸。`；
* Explosion 结束后播报：`这一轮是你。继续查看挑战。`。
